# Vrinda Store Annual Report 2026 | Excel

## Project Overview

This project focuses on analyzing Vrinda Store's annual sales data to understand sales performance, order status, customer purchasing patterns, gender-based sales distribution, and geographical sales trends.

Using Microsoft Excel, I organized and prepared the dataset, applied text and IF functions, created PivotTables, and developed an interactive dashboard with slicers and charts to present key business insights.

The objective of this project is to transform raw sales data into meaningful information that can help businesses understand their performance and make data-driven decisions.

## Project Objectives

- Analyze overall sales and order performance.
- Understand order status distribution, including delivered, cancelled, refunded, and returned orders.
- Compare sales across male and female customers.
- Analyze sales distribution across different cities.
- Identify the top five cities based on sales.
- Explore monthly sales trends and channel-wise performance.
- Build an interactive dashboard for business reporting.

## Data Preparation

The raw dataset was prepared for analysis using Excel functions and organized into a structured format suitable for PivotTable analysis and dashboard development.

### Functions Applied

- **Text Functions:** Used to process and organize text-based data.
- **IF Function:** Used to classify or categorize data based on specified conditions.

## Dashboard Features

### Interactive Slicers

The dashboard includes slicers for:

- Month
- Sales Channel
- Product Category

These filters allow users to explore sales performance across different months, channels, and product categories.

### Key Visualizations

The dashboard includes the following charts:

- **Order Status:** Displays the distribution of orders across delivered, cancelled, refunded, and returned statuses.
- **Orders vs. Sales:** Compares order volume with sales performance.
- **Sales Analysis:** Presents sales trends and performance.
- **Men vs. Women:** Compares sales across male and female customers.
- **Top Five Cities:** Highlights the five leading cities based on sales.
- **Gender Ratio:** Shows the gender distribution of customers or orders represented in the dataset.

## PivotTable Analysis

Separate PivotTables were created to summarize the data and support the dashboard visualizations.

| PivotTable        | Analysis                                                  |
| ----------------- | --------------------------------------------------------- |
| Order Status      | Count of Order ID and sum of sales amount by order status |
| Men vs. Women     | Sum of sales amount by gender                             |
| Gender Ratio      | Gender distribution based on the selected measure         |
| Top Five Cities   | Sum of sales amount by city                               |
| Monthly Sales     | Sales performance across months                           |
| Channel Analysis  | Sales performance across different sales channels         |
| Category Analysis | Sales distribution across product categories              |
